# CutFlow · 视频剪辑 Agent

面向广告主的视频剪辑工作台。可上传有权使用的素材，描述广告目标，选择剪辑技能，检查文字方案和局部修改预览，再生成带背景音乐的成片。无素材时可尝试搜索公开素材；搜索结果和使用权限仍需人工核对。

## 本地运行

需要 Node.js 24、npm。首次安装需要网络和 FFmpeg 相关依赖下载。

```bash
npm ci
cp .env.example .env
npm run dev
```

打开 <http://127.0.0.1:5173/>。前端开发服务器依赖本机 API（默认 4318 端口）；此仓库不是纯静态网站，GitHub 仓库或 GitHub Pages 不能直接提供完整的视频剪辑服务。

`npm run build` 检查并构建前端，`npm test` 执行测试。语音合成和远程素材检索依赖额外的服务、网络和相应权限；未配置时部分技能会提示补充条件。

## 使用与数据

1. 在「创作」中上传视频，或描述广告需求并选择技能。
2. 检查文字方案；确认后生成预览。修改建议先锁定最小片段，确认局部效果后再应用于整片。
3. 检查画面、字幕、声音和素材使用权，再导出。

本地项目、上传素材、生成视频、账号凭证及配置保存在 `.local/`，不会包含在本仓库。`.env` 也不会被提交。公开部署前需要独立配置鉴权、隔离存储、资源限额和素材授权审核；不要把本地开发服务直接作为多人共享的生产服务。

## 素材与许可

仓库包含 5 首 Kevin MacLeod 的 CC BY 4.0 配乐。曲目名称、作者、来源和完整署名文字见 `assets/music/catalog.json`；使用或分发配乐时需遵守其中的署名要求和 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 条款。

技能范例引用外部视频作为观看参考，不作为可再剪辑的授权素材。本仓库未收录第三方范例视频与其封面截图；界面会显示标题占位，播放时尝试打开原视频。任何通过联网搜索获得的素材，须在使用前核对来源和授权。

项目代码未附开放源代码许可证。公开仓库允许浏览代码，但不表示授予复用或再发布代码的许可。
